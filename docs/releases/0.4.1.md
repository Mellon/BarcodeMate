BarcodeMate 0.4.1 simplifies device synchronization and recovers automatically when the first connection attempt fails.

- Home labels shows the QR code beside one short explanation. **Copy link** includes a hint explaining that opening it on another computer synchronizes the list. Both descriptions are available in all 24 languages.
- Removed the duplicate start button, repeated errors and manual-code controls from the computer panel. The receiving device still confirms before joining and sharing the project.
- Failed initial invitations retry automatically. Rate limits wait one minute before retrying. Ending sharing keeps the local copy and prepares a fresh QR code.
- Restored sessions retain their connected state immediately after reopening the workspace.

Source commit: `SOURCE_COMMIT`. Validated package workflow: https://github.com/Mellon/BarcodeMate/actions/runs/SOURCE_RUN

Shared projects still use the existing HTTPS gateway and temporary server memory for up to 24 hours. API credentials remain on the server. Installers are unsigned, Mac packages are not notarized, and physical-phone microphone and printer checks remain separate from automated validation.
