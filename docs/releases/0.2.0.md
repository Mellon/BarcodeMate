BarcodeMate 0.2.0 adds **24 application languages**, matching the languages available on the website.

### New in 0.2.0

- Full interface dictionaries with 408 messages per language: navigation, import, sequences, layout/printing, native app menus, accessibility labels and app validation messages.
- System-language selection on first launch, including Simplified/Traditional Chinese regional handling.
- A visible language selector at the bottom of the sidebar. Your choice survives application restarts.
- Right-to-left interface layouts for Arabic, Persian and Hebrew. Barcode data and physical print geometry remain unchanged.
- Translations are bundled in the app; no account, internet connection or runtime translation service is needed.

Languages: English, Simplified Chinese, Traditional Chinese, Spanish, French, German, Portuguese, Japanese, Korean, Italian, Russian, Arabic, Hindi, Indonesian, Turkish, Vietnamese, Thai, Polish, Dutch, Ukrainian, Malay, Bengali, Persian and Hebrew.

Native operating-system dialogs follow OS language settings. Technical details from third-party encoders may retain their original wording. Translation improvements are welcome.

### Downloads

- **Windows x64:** `BarcodeMate-0.2.0-win-x64.exe` for 64-bit Intel / AMD PCs.
- **Mac Apple Silicon:** `BarcodeMate-0.2.0-mac-arm64.dmg`, macOS 13 or later.
- **Mac Intel:** `BarcodeMate-0.2.0-mac-x64.dmg`, macOS 13 or later.
- Mac ZIP packages, SHA-256 checksums and third-party notices are included.

**Signing:** Windows packages are not publisher-signed. Mac packages are not Developer ID-signed or notarized. Your operating system may warn or block installation. There is no automatic updater; install the new version to upgrade. Saved `.barcodemate` project files remain compatible.

### Verification

Packages are built from `SOURCE_COMMIT`. [Build and installation tests](https://github.com/Mellon/BarcodeMate/actions/runs/SOURCE_RUN).

Twelve core/localization tests cover all 108 barcode formats, data preservation, label geometry, language negotiation and dictionary completeness. Six Electron workflows cover export, batch import, labels/PDF, local image decoding, security settings and all 24 language choices across five tabs. The language test also checks native menu labels, project data preservation and language persistence after restarting the application. CI repeats the app workflows against the installed Windows executable and the extracted Mac package.

Intel Mac hardware, physical printers/scanners and all Windows display scaling configurations remain unverified. Test a printed sample before a large run. Direct XLSX import and complete BCStudio professional feature parity are not included.
