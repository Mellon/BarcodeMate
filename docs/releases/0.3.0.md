BarcodeMate 0.3.0 adds a household label workspace alongside the existing barcode tools.

- Kitchen starter labels in 24 languages, with separate Kitchen and Storage boxes collections. Edited names, quantities, zero-count labels and dates survive category switches and restarts.
- Compact editable name and quantity badges. Individual copies can have different best-before dates; selecting a date highlights matching labels without changing quantity controls.
- A4, US Letter, round labels and custom millimetre layouts. Region and language reorder suggestions without hiding sizes.
- Manually adjustable physical preview with saved screen calibration, visible label gutters and positive or negative print adjustments. Preview highlights do not appear in print or PDF.
- Automatic local saving, undo and portable JSON backup import/export. Scenario shortcuts can be added to and removed from navigation.
- Optional voice input through BarcodeMate's HTTPS gateway. Audio and the current label list are sent only when voice input is used; API keys stay on the server. Operators can override or disable the gateway using `BARCODEMATE_HOME_API`. Basic editing and printing work offline.

Source commit: `SOURCE_COMMIT`. Validated package workflow: https://github.com/Mellon/BarcodeMate/actions/runs/SOURCE_RUN

This release keeps the existing barcode workflows and their project format. Household labels use a separate JSON format that can also be used on the website.

Installers remain unsigned and macOS packages are not notarized. Real printers, label stock and hardware microphones still require hands-on verification. Start with a plain-paper alignment test and print at actual size.
