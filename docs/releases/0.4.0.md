BarcodeMate 0.4.0 connects phone inventory with desktop label printing.

- Open Home labels and scan the QR code displayed under **Sync with phone**, then connect in the mobile web page. An eight-digit code is also available. No account or shared Wi-Fi is required. The computer keeps its waiting code available automatically; the project is only uploaded after the phone connects.
- Edit quantities and names, or use the microphone on the phone; the computer updates its label preview. Printing remains an explicit action on the computer.
- Pairing controls and connection messages in all 24 interface languages. The phone prioritizes voice input and inventory, leaving paper setup and printing on the computer.
- Offline changes remain in the current tab's session storage and retry after reconnection. Updates carry unique operation IDs. Conflicting changes show both item lists and require an explicit choice of the entire project version.
- Pairing accepts one phone. While the computer page is open, its invitation automatically stays valid. After a long absence, an expired invitation is replaced automatically. This does not interrupt an established connection. Shared projects are temporarily held in server memory for up to 24 hours, or until either device ends sharing or the service restarts. Local projects remain separate from this temporary session; export a backup before closing a tab if work has not synchronized.
- Voice updates preserve edited badge identities and existing per-copy dates. New copies stay undated. Recording is stopped when the page moves to the background where supported.

Source commit: `SOURCE_COMMIT`. Validated package workflow: https://github.com/Mellon/BarcodeMate/actions/runs/SOURCE_RUN

Optional pairing and voice use BarcodeMate's HTTPS gateway through the native bridge. The renderer does not gain arbitrary network access. API credentials remain on the server; use `BARCODEMATE_HOME_API` to override or disable the gateway. Normal local label editing and printing remain available without it.

Installers are unsigned; macOS packages are not notarized. Real iPhone/Android microphone permission flows, physical printers and label stock still require hands-on verification. Mobile browser automation and synthetic audio do not replace those checks.
