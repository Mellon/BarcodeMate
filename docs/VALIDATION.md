# Validation — 2026-09-17

## Completed locally on macOS / Apple Silicon

- TypeScript strict checking and production bundling.
- Nine core tests, including all 108 barcode format samples, retail check digits, large integer sequences, CSV mapping/leading zeros/multiline fields, page filling/offset/quantities, validation, rotation/captions and GS1/Wi-Fi/vCard helpers.
- Five real Electron end-to-end tests: SVG and project save; sequence → editable batch → two-page PDF; CSV mapping → ZIP with invalid-row failure; sandbox/network restrictions plus library and language switching; six image exporters plus decoding exported QR content with ZXing.
- Electron 44.4.1 isolation and sandbox checked from the actual preload context. Renderer fetch to an external domain fails. Only bundled application resources and local data are allowed.
- `pdfinfo` confirms the 23-label test output contains two A4 pages with no JavaScript. Page 1 was rasterized and visually inspected: 21 ordered labels.
- macOS `sips` independently reads PNG, TIFF, BMP and JPEG as 264 × 240 pixels at approximately 300 DPI. PNG/TIFF/JPEG report 300.000 DPI; BMP reports 299.999 due to pixels-per-meter rounding.
- npm audit after dependency updates: zero reported vulnerabilities at the time of the check.
